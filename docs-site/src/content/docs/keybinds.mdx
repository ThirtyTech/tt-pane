## Place a window

All defaults use **Ctrl + Alt** on Windows and Linux, or **Control + Option** on macOS. Digits are on the **number row**, not the numpad.

| Key with Ctrl + Alt | Position | Initial size |
| --- | --- | --- |
| 1 | Left half | 50% width, full height |
| 2 | Right half | 50% width, full height |
| 3 | Center | 50% width and height, centered on both axes |
| 4 | Bottom left | 50% width and height |
| 5 | Bottom half | Full width, 50% height |
| 6 | Bottom right | 50% width and height |
| 7 | Top left | 50% width and height |
| 8 | Top half | Full width, 50% height |
| 9 | Top right | 50% width and height |
| 0 | Fill work area | Full width and height |

Every placement targets the active window on its current monitor. A window spanning displays uses the display with the largest overlap; an off-screen window uses the nearest display. Application minimum sizes can limit the result.

## Resize and fill

| Shortcut | Action |
| --- | --- |
| Ctrl + Alt + - | Shrink current width by 25% |
| Ctrl + Alt + = | Expand current width by 25% |
| Ctrl + Alt + Shift + 8 | Fill the last saved gap with a different window |
| Ctrl + Alt + ↑ | Move the shared horizontal boundary up (Windows) |
| Ctrl + Alt + ↓ | Move the shared horizontal boundary down (Windows) |

Expansion uses the `=` / `+` key **without Shift**. Ctrl + Alt + Shift + = also expands unless assigned to another action. Gap filling uses Shift + 8 (`*` on the number row). Numpad keys can be recorded separately.

Read [Resize & refine](/tt-pane/resizing/) for anchoring, growth cycles, and neighboring-window behavior.

## Move focus — Windows

| Shortcut | Direction |
| --- | --- |
| Ctrl + Alt + H | Left |
| Ctrl + Alt + J | Down |
| Ctrl + Alt + K | Up |
| Ctrl + Alt + L | Right |

Outside centered groups, focus moves to the nearest window by center distance within a 90° cone, including across monitors. Ungrouped windows stay in place. Spatial navigation has no wraparound; focus stays put if there is no candidate. A grouped destination returns to its saved center.

Snapped windows are considered even when covered. Their current frame must fit within the monitor work area and touch an edge (within two pixels), covering halves, quarters, resized edge layouts, and native Windows snaps. Moving a window into the middle removes this exemption. Only middle/floating windows require at least 50% of their full frame to be on-screen and uncovered by default. Enable **Settings → Window focus → Include obscured windows** to also include covered middle/floating or off-screen windows. Minimized, hidden, cloaked, and utility windows remain excluded. Focus and paired boundary resizing are currently Windows-only.

Hold **Ctrl + Alt + H/L** for **400 ms** to jump directly to a snapped window in that direction on the same monitor, skipping all middle/floating windows and centered-group members. The jump fires once per hold; release before 400 ms for a normal step. If no snapped window qualifies, focus stays put. This also works with remapped left/right focus shortcuts and requires the running Windows tray app.

## Centered groups — Windows

Press **Ctrl + Alt + 3** on each window you want in a group. Windows must be on the same monitor and placed using Center; dragging them to the middle does not enroll them.

The focused window returns to its saved centered position. Other members keep their size and stagger left or right and down in successive steps of up to **25% of the focused window's width and height**. Spacing shrinks independently on each side as needed to fit every window inside the monitor work area. There is no rotation. Earlier members sit to the left and later members to the right in enrollment order; members farther away in that order receive larger offsets.

**Ctrl + Alt + H/L** steps through members in enrollment order, including covered peers regardless of the visibility toggle. As you press L, visited members shift left. At either end, the next H/L press reaches a background window in that direction on the same monitor, skipping group members. If there is no candidate, focus stays put. **J/K** leaves the group for background windows on the same monitor: J selects below and K above, preferring the leftmost column (bottom-left/top-left in a quarter layout), even on wide screens. Other group members are skipped. Clicking or Alt+Tabbing to a member also centers it while tt-pane runs in the tray.

Moving or resizing a member manually, another placement/width shortcut, changing monitors/work areas, minimizing, maximizing, hiding, or closing removes membership. Center explicitly rejoins the window. Repeated Center presses still grow the focused window and update its saved centered size. Groups are independent per monitor.

CLI Center/focus actions share the same saved groups. Mouse and Alt+Tab observation requires the running tray app.

## Change a shortcut

1. Open **Settings…** from the tray menu.
2. Click a shortcut and press your replacement combination.
3. Press **Escape** to cancel recording, or **Backspace** to disable that action.
4. Select **Save changes**.

Duplicate shortcuts are rejected. Native registration conflicts appear in Settings; failed registration preserves the previous bindings. On Wayland, export and reload compositor bindings after saving. See [platform setup](/tt-pane/platforms/).

Older configurations gain missing focus actions unless a default key is already taken. Existing custom or disabled bindings are preserved. Older configurations may need the two boundary shortcuts recorded manually, or defaults reset and saved.
