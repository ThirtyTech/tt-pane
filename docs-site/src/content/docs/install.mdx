## Quick install

Choose the app package or install script for your platform. Each script downloads the latest release, checks it against the release's `SHA256SUMS.txt`, and installs tt-pane for your account. Rerun the same command to upgrade.

<Tabs syncKey="os">
  <TabItem label="Windows">
    In PowerShell:

    ```powershell
    powershell -ExecutionPolicy Bypass -c "irm https://github.com/ThirtyTech/tt-pane/releases/latest/download/install.ps1 | iex"
    ```

    The script runs the setup silently and accepts its defaults: a per-user install into `%LOCALAPPDATA%\Programs\tt-pane` with a Start menu shortcut, no administrator rights, and no prompts. A running tt-pane is closed for the upgrade, and tt-pane starts in the tray afterwards.

    Supports Windows 10 and 11 on x64. Windows 11 on ARM runs the x64 build through emulation.
  </TabItem>
  <TabItem label="macOS">
    Download the `.dmg` from [GitHub Releases](https://github.com/ThirtyTech/tt-pane/releases), open it, and drag **tt-pane** to **Applications**. Open it from Applications, Launchpad, or Spotlight. It runs in the menu bar without a terminal or Dock icon.

    Allow Accessibility access under **System Settings → Privacy & Security → Accessibility** when prompted. Settings opens with instructions until access is granted. Reopening the app shows Settings in the running instance.

    Unless the release says the app is notarized, macOS blocks the first launch: choose **Done**, then **System Settings → Privacy & Security → Open Anyway**.

    For the standalone command-line executable instead, run in Terminal:

    ```sh
    curl -fsSL https://github.com/ThirtyTech/tt-pane/releases/latest/download/install.sh | sh
    ```

    The script installs only the executable into `~/.local/bin`, not the app bundle.

    Then run `~/.local/bin/tt-pane` to start it in the menu bar, and grant the installed executable Accessibility access under **System Settings → Privacy & Security → Accessibility**. Upgrades replace the unsigned executable, so macOS can ask for that access again.

    Supports Apple Silicon. Intel Macs are not supported.
  </TabItem>
  <TabItem label="Linux">
    In a terminal:

    ```sh
    curl -fsSL https://github.com/ThirtyTech/tt-pane/releases/latest/download/install.sh | sh
    ```

    The script installs `tt-pane` into `~/.local/bin`, plus a **tt-pane** app launcher and icon under `~/.local/share`. Start it from your app launcher. The script also warns about shared libraries tt-pane needs that aren't installed; see [Platforms & troubleshooting](/tt-pane/platforms/) for native dependencies and a tray host.

    Supports x64.
  </TabItem>
</Tabs>

### Script options

Set these environment variables before the command, such as `curl -fsSL … | TTPANE_VERSION=v0.2.0 sh` or `$env:TTPANE_VERSION = 'v0.2.0'; irm … | iex`.

| Variable | Platforms | Effect |
| --- | --- | --- |
| `TTPANE_VERSION` | All | Install a specific release, such as `v0.2.0`, instead of the latest. |
| `TTPANE_PREFIX` | macOS, Linux | Install under another prefix instead of `~/.local`. For every user, use `/usr/local` and run the script with `sudo`. |
| `TTPANE_TASKS` | Windows | Optional shortcuts: `desktopicon` (desktop shortcut). Unset, a new install has none and an upgrade keeps your earlier choice; `''` turns it off. The former `startup` task is ignored; see launch at login below. |
| `TTPANE_NO_LAUNCH` | Windows | Set to `1` to not start tt-pane after installing. |

## Download tt-pane

To install by hand instead, choose the matching package from [GitHub Releases](https://github.com/thirtytech/tt-pane/releases). Packages appear after a matching version tag is published.

| Platform | Package | Start |
| --- | --- | --- |
| Windows x64 | `tt-pane-vVERSION-windows-x64-setup.exe` | Install, then launch tt-pane from Start |
| Windows x64, portable | `.zip` | Extract and run the executable |
| macOS Apple Silicon | `.dmg` | Drag tt-pane to Applications and open it |
| macOS Apple Silicon, CLI | `.tar.gz` | Extract, then run `./tt-pane` |
| Linux x64 | `.tar.gz` | Extract, then run `./tt-pane` |

Windows installation is per-user and needs no administrator rights. The installer offers an optional desktop shortcut; launch at login is managed in Settings. Linux archives and the macOS CLI archive contain standalone executables. The macOS disk image contains the app bundle. See [Platforms & troubleshooting](/tt-pane/platforms/) for permissions and native dependencies.

Windows and Linux packages are unsigned. The macOS app is signed and notarized when release credentials are configured, and signed ad hoc otherwise. Each release includes `SHA256SUMS.txt`. Check your file with `Get-FileHash -Algorithm SHA256` on Windows, `shasum -a 256` on macOS, or `sha256sum` on Linux.

## Your first placement

1. Launch tt-pane. It starts in the tray without opening a settings window.
2. Select a window and press **Ctrl + Alt + 1** to place it in the left half.
3. Press **Ctrl + Alt + 2** to move it to the right half.
4. Try **Ctrl + Alt + 3** to center it at half width and half height.

On macOS, use **Control + Option**. On GNOME Wayland, log out and back in once after the first launch so GNOME loads the tt-pane extension ([details](/tt-pane/platforms/#gnome-on-wayland)).

Open **Settings…** from the tray to customize shortcuts. Closing Settings leaves tt-pane running; **Quit tt-pane** exits. Run one tray instance at a time. Reopening the macOS app from Finder shows Settings; general single-instance forwarding is not implemented.

## Upgrade or uninstall

Your configuration is kept when you upgrade or uninstall.

<Tabs syncKey="os">
  <TabItem label="Windows">
    To upgrade, rerun the install script; it closes the running tt-pane for you. Or quit tt-pane from its tray menu and rerun the setup. In the setup, deselecting a previously selected shortcut removes it.

    To uninstall from PowerShell:

    ```powershell
    $env:TTPANE_UNINSTALL = '1'; irm https://github.com/ThirtyTech/tt-pane/releases/latest/download/install.ps1 | iex
    ```

    Or use **Settings → Apps → Installed apps → tt-pane**.
  </TabItem>
  <TabItem label="macOS">
    For the app, quit tt-pane and replace it in Applications with the new version. An ad-hoc-signed update may need Accessibility turned off and on again. To uninstall the app, turn off **Launch at login** and save, quit tt-pane, then remove it from Applications.

    For a script install, rerun the install script to upgrade, then quit and restart tt-pane. To uninstall the script installation:

    ```sh
    curl -fsSL https://github.com/ThirtyTech/tt-pane/releases/latest/download/install.sh | sh -s -- --uninstall
    ```

    Pass the same `TTPANE_PREFIX` you installed with, if any.
  </TabItem>
  <TabItem label="Linux">
    To upgrade, rerun the install script, then quit tt-pane from the tray and start it again.

    To uninstall, which also removes the app launcher and icon:

    ```sh
    curl -fsSL https://github.com/ThirtyTech/tt-pane/releases/latest/download/install.sh | sh -s -- --uninstall
    ```

    Pass the same `TTPANE_PREFIX` you installed with, if any.
  </TabItem>
</Tabs>

tt-pane starts at sign-in on Windows, macOS and Linux once you have opened it. Turn this off in **Settings → General → Launch at login**; see [configuration](/tt-pane/configuration/#launch-at-login).

## Build from source

Install a recent stable Rust toolchain and the [native build prerequisites](https://github.com/thirtytech/tt-pane#build-prerequisites), then run from the repository:

```sh
cargo run --release
```

For the command-line positioning tool without GPUI:

```sh
cargo build --release --no-default-features
```
